# 智能药箱助手项目手动配置指南

## 一、后端配置

### 1. 环境准备

#### 1.1 安装 Python
确保您的系统已安装 Python 3.7 或更高版本。

#### 1.2 安装依赖包
在 `MedicineBoxBackend` 目录下执行以下命令安装所需的依赖包：

```bash
pip install fastapi uvicorn sqlalchemy pymysql python-jose[cryptography] passlib[bcrypt] python-multipart
```

### 2. 数据库配置

#### 2.1 安装 MySQL
确保您的系统已安装 MySQL 数据库服务器。

#### 2.2 创建数据库
1. 登录 MySQL 数据库：
   ```bash
   mysql -u root -p
   ```

2. 创建 `medicine_box` 数据库：
   ```sql
   CREATE DATABASE medicine_box CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   ```

3. 验证数据库是否创建成功：
   ```sql
   SHOW DATABASES;
   ```

#### 2.3 修改数据库连接配置
编辑 `MedicineBoxBackend/database.py` 文件，修改数据库连接字符串：

```python
# MySQL 数据库连接网址
# 格式: mysql+pymysql://用户名:密码@主机地址:端口/数据库名
SQLALCHEMY_DATABASE_URL = "mysql+pymysql://root:root@127.0.0.1:3306/medicine_box"
```

根据您的 MySQL 配置，修改以下参数：
- `root`：MySQL 用户名
- `root`：MySQL 密码
- `127.0.0.1:3306`：MySQL 主机地址和端口
- `medicine_box`：数据库名称

### 3. 启动后端服务

在 `MedicineBoxBackend` 目录下执行以下命令启动后端服务：

```bash
python main.py
```

服务将在 `http://127.0.0.1:8000` 上运行。
