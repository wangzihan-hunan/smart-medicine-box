# 用药管理模块接口参数设计

## 1. 添加提醒接口 (POST /api/medication/reminders)

### 请求参数

#### Header 参数
| 参数名 | 类型 | 必选 | 描述 | 示例 |
|-------|------|------|------|------|
| Authorization | string | 是 | OAuth 2.0 认证令牌，格式为 "Bearer {token}" | Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9... |

#### Body 参数 (ReminderCreate)
| 参数名 | 类型 | 必选 | 描述 | 示例 |
|-------|------|------|------|------|
| medicine_name | string | 是 | 药品名称 | 阿莫西林 |
| time | string | 是 | 提醒时间，格式为 "HH:MM" | 08:00 |
| dosage | string | 是 | 用药剂量 | 1片 |
| is_repeat | boolean | 是 | 是否每天重复 | true |

### 请求示例
```json
POST /api/medication/reminders
Content-Type: application/json
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

{
  "medicine_name": "阿莫西林",
  "time": "08:00",
  "dosage": "1片",
  "is_repeat": true
}
```

### 响应参数

#### 成功响应 (200 OK)
| 参数名 | 类型 | 描述 | 示例 |
|-------|------|------|------|
| code | integer | 状态码 | 200 |
| status | string | 状态 | success |
| message | string | 操作成功的提示信息 | 成功添加 08:00 服用 阿莫西林 的提醒！ |
| data | object (AddReminderData) | 响应数据 | - |
| data.reminder_id | integer | 提醒ID | 1 |
| data.medicine_name | string | 药品名称 | 阿莫西林 |
| data.time | string | 提醒时间 | 08:00 |

#### 响应示例
```json
{
  "code": 200,
  "status": "success",
  "message": "成功添加 08:00 服用 阿莫西林 的提醒！",
  "data": {
    "reminder_id": 1,
    "medicine_name": "阿莫西林",
    "time": "08:00"
  }
}
```

## 2. 获取今日提醒接口 (GET /api/medication/today)

### 请求参数

#### Header 参数
| 参数名 | 类型 | 必选 | 描述 | 示例 |
|-------|------|------|------|------|
| Authorization | string | 是 | OAuth 2.0 认证令牌，格式为 "Bearer {token}" | Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9... |

### 请求示例
```
GET /api/medication/today
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

### 响应参数

#### 成功响应 (200 OK)
| 参数名 | 类型 | 描述 | 示例 |
|-------|------|------|------|
| code | integer | 状态码 | 200 |
| status | string | 状态 | success |
| message | string | 操作成功的提示信息 | 获取今日提醒成功 |
| data | object (ReminderListData) | 响应数据 | - |
| data.total_reminders | integer | 提醒总数 | 2 |
| data.list | array[ReminderSchema] | 提醒列表 | - |
| data.list[].id | integer | 提醒ID | 1 |
| data.list[].user_id | integer | 用户ID | 1 |
| data.list[].medicine_name | string | 药品名称 | 阿莫西林 |
| data.list[].time | string | 提醒时间 | 08:00 |
| data.list[].dosage | string | 用药剂量 | 1片 |
| data.list[].is_repeat | boolean | 是否每天重复 | true |

#### 响应示例
```json
{
  "code": 200,
  "status": "success",
  "message": "获取今日提醒成功",
  "data": {
    "total_reminders": 2,
    "list": [
      {
        "id": 1,
        "user_id": 1,
        "medicine_name": "阿莫西林",
        "time": "08:00",
        "dosage": "1片",
        "is_repeat": true
      },
      {
        "id": 2,
        "user_id": 1,
        "medicine_name": "布洛芬",
        "time": "12:00",
        "dosage": "1片",
        "is_repeat": false
      }
    ]
  }
}
```

## 3. 接口依赖说明

1. **认证依赖**：两个接口都需要在 Header 中提供有效的 JWT 令牌，令牌可以通过登录接口 (/api/auth/login) 获取。

2. **数据库依赖**：
   - 添加提醒接口会向数据库的 reminders 表插入一条新记录。
   - 获取今日提醒接口会从数据库的 reminders 表查询当前用户的所有提醒记录。

3. **权限控制**：接口会验证当前用户的身份，确保用户只能操作自己的提醒数据。

## 4. 错误处理

### 常见错误响应

| 状态码 | 状态 | 消息 | 说明 |
|-------|------|------|------|
| 401 | error | 未授权 | 缺少有效的认证令牌或令牌已过期 |
| 422 | error | 请求参数错误 | 请求体参数格式不符合要求 |
| 500 | error | 服务器内部错误 | 服务器处理请求时发生错误 |
